# Generative AI for Synthetic Fraud Detection (Elliptic Dataset Guide)

Welcome! This hands-on project guides you from complete scratch on how to build a **Generative AI model** that generates realistic synthetic cryptocurrency transactions for fraud detection, modeled after the **Kaggle Elliptic Bitcoin Dataset**.

---

## 1. What is This Project & Why Does It Matter?

In real-world finance and cryptocurrency networks (like Bitcoin):
- **Legitimate transactions** make up over **98%** of all activity.
- **Fraudulent / Criminal transactions** (money laundering, ransomware, darknet markets) make up only **~2%**.

Because fraud is so rare, anti-fraud AI models struggle to learn what criminal patterns look like. 

**The Solution:** We build a **Generative AI model** (a neural network) that acts like a flight simulator. It learns the statistical distribution and graph structures of real money laundering, and generates thousands of realistic **synthetic fraud transactions** to train and bulletproof detection systems without exposing sensitive real-world records.

## 3. Step-by-Step Instructions (Run in Order)

Open your terminal or command prompt in this directory (`C:\Users\harsh\.gemini\antigravity\scratch\synthetic-fraud-elliptic`):

### Step 1: Create or Load Data
If you don't have the 500MB Kaggle dataset downloaded yet, this creates a realistic mini sample so you can learn right away:
```powershell
python 01_generate_sample_elliptic.py
```
*(If you have downloaded the real Kaggle dataset, simply unzip its 3 CSV files into the `data/` folder instead!)*

### Step 2: Explore the Graph and Features
Understand what transactions, graph edges, and feature numbers represent:
```powershell
python 02_explore_graph.py
```

### Step 3: Train the Generative AI Model
This script trains a PyTorch **Conditional Generative Adversarial Network (cGAN)**:
- The **Generator** learns how money laundering transactions look.
- The **Discriminator** tries to spot real vs. synthetic.
- Once trained, it synthesizes 500 new fraudulent transactions!
```powershell
python 03_train_generative_model.py
```

### Step 4: Evaluate the Synthetic Data (The Truth Test)
Checks if the synthetic transactions have the same statistical signatures as real fraud, and tests if augmenting your training set with synthetic data improves fraud detection:
```powershell
python 04_evaluate_synthetic.py
```
